# خرده‌حساب

بازی پازل فارسی برای اندروید. پشت پیشخوان یک مغازه‌ی کوچک ایستاده‌ای: بقیه‌ی پول هر مشتری را دقیق و با کمترین تکه بده، ولی حواست به دخل باشد؛ پولی که الان خرج می‌کنی، برای مشتری بعدی نیست.

- بدون اینترنت، بدون تبلیغ، بدون جمع‌آوری اطلاعات
- ۶۰ روز در ۴ مغازه: دکه، بقالی، قنادی، سوپرمارکت
- روز ویژه‌ی هر روز، شیفت بی‌پایان، آلبوم مشتری‌ها

## نصب

از بخش **Releases** همین صفحه، آخرین فایل `khordeh-hesab.apk` را دانلود کنید و باز کنید. اگر گوشی اجازه نداد، یک بار اجازه‌ی نصب از مرورگر را بدهید.

برای اطمینان از سالم بودن فایل، هش SHA-256 آن باید با فایل `khordeh-hesab.apk.sha256` همان نسخه یکی باشد.

---

Khordeh-Hesab is an offline Persian change-making puzzle game for Android. This repository holds release builds only.
